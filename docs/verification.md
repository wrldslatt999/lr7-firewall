# Протокол локальної перевірки (27.11.2026)

**Важливо:** цей протокол фіксує виконання в окремому локальному Linux-середовищі підготовки проєкту. Він **не є результатом виконання в Kali Linux користувача**.

Команда:

```bash
python -m unittest discover -s tests -q
```

Результат: `Ran 43 tests`, `OK`.

Друга команда:

```bash
python -m tools.run_demo --out reports/local-demo.json
```

Результат: `pass: true`. Перевірено дозволений TCP- і UDP-обмін, вхідне блокування TCP, тимчасове відключення й відновлення правила без рестарту, виявлення перетинів, роботу пріоритетів і вихідне блокування UDP. Журнал за один запуск містив 18 подій, з них 3 відмови: 2 TCP, 1 UDP. Результати часу, адреси й статистика відтворюються в кожному запуску й можуть відрізнятися.

Після виконання користувачем у Kali додаткові дані мають бути отримані через `python3 -m tools.run_demo --out docs/kali-demo.json`, а не скопійовані із цього документа. Це надає підтвердження роботи саме у вибраному середовищі.
